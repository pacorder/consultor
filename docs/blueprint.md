# **App Name**: SEM Consultores

## Core Features:

- Hero Section with Statistics: Display professional photo, impressive statistics, and value proposition.
- About Me Section: Showcase complete biography, certifications, and areas of expertise.
- Service Listings: Detail the four core services offered with a four-step methodology.
- Success Case Studies: Present three case studies with quantifiable results and ROI.
- Client Testimonials: Showcase client reviews with ratings.
- Blog Articles: Publish three articles categorized by relevant topics.
- Consultation Booking and Contact Forms: Allow potential clients to submit contact forms and reserve consultation times using interactive forms with toast notifications on submission and tab navigation.

## Style Guidelines:

- Primary color: The requested blue (#3b82f6) for a professional, trustworthy feel.
- Background color: Light gray (#f9fafb), a desaturated version of the primary color, providing a clean backdrop for content.
- Accent color: A slightly darker blue (#2563eb) analogous to the primary color for interactive elements and highlights.
- Body and headline font: 'Inter' (sans-serif) as requested, for a modern, objective feel.
- Fixed header for clear navigation across all pages.
- Comprehensive footer with contact information.
- Use Shadcn components such as cards, buttons, forms, and tabs for a consistent UI.
- Responsive design for optimal viewing on mobile devices.
